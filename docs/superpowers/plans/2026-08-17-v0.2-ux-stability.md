# proc-lens v0.2 UX / Stability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the TUI stable under live refresh, keep selection anchored to a PID, correct desktop-process classification, and improve inspection/navigation without adding new dependencies.

**Architecture:** Keep `/proc` collection and CLI output raw/deterministic. Add UI-only presentation state in `src/ui/model.rs` for CPU EMA, stable ordering, PID selection reconciliation, pause state, and navigation. Keep classification/project identity in `classifier` and `app`; keep rendering in `ui/dashboard.rs` and `ui/detail.rs`.

**Tech Stack:** Rust 2024, Rust >= 1.88, Ratatui 0.30, Crossterm 0.29, optional NVML through existing `nvml-wrapper`.

## Global Constraints

- Raw sampling cadence remains 1 second.
- Automatic table reorder cadence is 2 seconds.
- CPU display smoothing uses EMA `0.35 * new + 0.65 * previous` keyed by `ProcessIdentity`.
- CPU stable-sort band width is 2 percentage points.
- No new dependencies.
- CLI `snapshot` and `inspect` remain based on raw values, not UI-smoothed values.
- Existing Ubuntu 22.04 CI and Rust 1.88 MSRV checks remain mandatory.
