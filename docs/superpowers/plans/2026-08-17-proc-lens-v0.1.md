# proc-lens v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a runnable Linux TUI/CLI process inspector that explains process provenance and project identity while reporting CPU/RAM and optional NVIDIA GPU usage.

**Architecture:** Keep raw Linux collection separate from interpretation. `collector` reads `/proc`, `process` builds identity/tree/provenance, `classifier` derives deterministic process type/project evidence, `cli` exposes snapshot/inspect, and `ui` renders the same enriched snapshot through Ratatui. GPU is an optional enrichment source merged by PID.

**Tech Stack:** Rust 2024 edition, Linux `/proc`, Ratatui, Crossterm, Clap, optional `nvml-wrapper`.

## Global Constraints

- Target Ubuntu 22.04 / Linux x86_64 first.
- Default refresh period is 1 second.
- Normal operation must not require root.
- No external shell commands in the hot sampling loop.
- Classification is deterministic and exposes evidence.
- GPU support is optional and must degrade cleanly when NVML is absent.
- Never fabricate per-process GPU percentage when only memory accounting is available.
- CPU sample identity is keyed by `(pid, start_time)` to avoid PID reuse errors.
- Performance acceptance targets are idle CPU < 1% and RSS < 50 MiB on a typical workstation; measure rather than assume.

## File Structure

- `Cargo.toml`: package metadata and dependencies.
- `src/lib.rs`: reusable library surface shared by binary and integration tests.
- `src/main.rs`: CLI entry point.
- `src/collector/{mod,cpu,memory,process}.rs`: parsing and live `/proc` sampling.
- `src/process/{mod,model,tree,resolver}.rs`: core models, parent chain/tree, ROS2 project identity.
- `src/classifier/{mod,rules}.rs`: process categories, scores, evidence, deterministic winner.
- `src/gpu/{mod,nvml}.rs`: optional GPU snapshot provider.
- `src/app.rs`: snapshot assembly, filtering, sorting, refresh state.
- `src/ui/{mod,dashboard,detail}.rs`: Ratatui dashboard and process detail rendering.
- `tests/proc_parser_tests.rs`: fixture parser behavior.
- `tests/resolver_tests.rs`: ROS2 path resolution.
- `tests/classifier_tests.rs`: evidence and category selection.
- `tests/tree_tests.rs`: tree/parent-chain edge cases.

fn process_stat_handles_spaces_and_parentheses_in_comm() {

    let stat = parse_process_stat(input).unwrap();
    assert_eq!(stat.pid, 321);
    assert_eq!(stat.name, "worker (camera) node");
    assert_eq!(stat.ppid, 12);
    assert_eq!(stat.utime_ticks, 100);
    assert_eq!(stat.stime_ticks, 25);
    assert_eq!(stat.start_time_ticks, 999);

#[test]
fn meminfo_uses_mem_available() {
    let input = "MemTotal:       1000 kB\nMemFree:         100 kB\nMemAvailable:    400 kB\n";
    let mem = parse_meminfo(input).unwrap();
    assert_eq!(mem.total_bytes, 1_024_000);
    assert_eq!(mem.available_bytes, 409_600);
    assert_eq!(mem.used_bytes(), 614_400);
}
