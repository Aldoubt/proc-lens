# proc-lens v0.2.3 Ubuntu Packaging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship proc-lens v0.2.3 as an Ubuntu amd64 `.deb` that installs a desktop launcher/icon and is automatically attached to a GitHub Release created from the `v0.2.3` tag.

**Architecture:** Keep runtime code unchanged. Add packaging metadata/assets around the existing release binary, validate the package as an archive, and publish only from a tag-triggered GitHub Actions workflow. Desktop launch uses the Freedesktop desktop entry contract with `Terminal=true` so the existing TUI opens in a terminal without hard-coding GNOME Terminal.

**Tech Stack:** Rust 2024, cargo-deb, Bash, Freedesktop `.desktop`, SVG/PNG assets, dpkg-deb, GitHub Actions, GitHub CLI.

## Global Constraints

- Packaging-only: no changes to process collection, classification, provenance, GPU, or TUI behavior.
- Version becomes `0.2.3`; MSRV remains Rust `1.88`.
- Ubuntu 22.04 x86_64 / amd64 is the only release target for v0.2.3.
- Runtime users must not need Cargo or Rust installed.
- `.desktop` must use `Exec=proc-lens`, `Icon=proc-lens`, and `Terminal=true`; do not hard-code `gnome-terminal`.
- Release publishing is tag-only and cannot run on ordinary branch pushes.
- Release is incomplete until GitHub Release `v0.2.3` contains `proc-lens_0.2.3-1_amd64.deb`.
